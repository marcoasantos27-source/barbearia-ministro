# Barbearia Ministro — V4

Landing page mobile-first da Barbearia Ministro, em Aracaju.

## V4 — refinamento

- hero com fotografia mais focada no trabalho de barbearia;
- serviços na ordem Cabelo, Barba e Cabelo + Barba;
- fotografias mais variadas entre serviços e portfólio;
- seção de assinaturas antes do portfólio;
- carrosséis com alinhamento e snap refinados no mobile;
- assinatura visual mais sóbria em preto/grafite e dourado;
- seção “O padrão Ministro” simplificada para “Trabalhos”;
- localização mais compacta;
- CTA fixo de agendamento menor.

As fotos são provisórias e podem ser substituídas pelas imagens reais da Barbearia Ministro sem alterar a estrutura.

## Rodar localmente

```bash
npm install
npm run dev
```
